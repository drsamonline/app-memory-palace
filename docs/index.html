Memory Palace

Walk a room to remember. Place things at spots, then recall them in the same order — and a miss is shown back where it belonged.

Status Built and working: eleven spots in one room; placing in order, which is the walk; a room that holds ten and refuses an eleventh while naming what it would have displaced; a recall test that shows each miss in its own room; remove and renumber; export and reload.
Release: Windows EXE, Android APK and Linux binary, built from this source in CI — app-latest.
Not built: multiple rooms, images, or a spaced-repetition schedule. The last one is deliberate: this must not become a flashcard app with a memory metaphor bolted on.

What it does

  • Places items at spots in a room, in order — the order is the walk you will recall.
  • Refuses an eleventh item in a room holding ten, and names the item it would have displaced.
  • Tests the walk: type the items in order, and every miss is shown back at its own spot.
  • Removes and renumbers, and keeps the palace across a reload.

What it will not do

  • Become a flashcard app. No interval, no ease factor, no due list.
  • Score you. A test reports right and wrong in order; there is no grade.
  • Silently drop an item when a room is full.
  • Start an empty palace over a broken one.
  • Use the internet. No fetch, no endpoint; CSP connect-src 'none'.

When things go wrong

CaseWhat happens
Bad inputNo item name, a spot that is not in the room, the same thing twice, removing something that is not there — each refused with the field named.
No networkNothing changes; the palace is on the device.
Storage full or unavailableNOT SAVED, and the palace on screen is unchanged.
Corrupt saved stateReported and offered for export; never replaced with an empty one.

How to run it

  • Here: play/index.html, or install it from your browser's menu.
  • Offline file: open docs/play/index.html straight from disk.
  • Tests: node tests/self-tests.js.
