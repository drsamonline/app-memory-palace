Memory Palace

Walk a room to remember. Place things at spots, then recall them in the same order.

about

Place something

Order is the walk. About ten spots per room, or the walk gets vague — an eleventh is refused and says what it would have displaced.

    Walk it back

    The order matters: a right thing at the wrong spot is still a miss, because the method is the walk.

    Type the items in the order you placed them. A miss is shown back in its own room.

      Memory Palace keeps the palace on this device. It is not a flashcard app: there is no schedule, no ease factor and no due list — the palace is the method and the score is not the point.
